# 추가 자료

Rust 패턴을 더 깊이 공부할 때 참고할 수 있는 강연과 온라인 책을 소개합니다. 링크의 내용은 이 안내서와 별도로 관리되므로, 최신 정보와 라이선스는 각 원본 사이트에서 확인하세요.

## 강연

- Nicholas Cameron의 [Design Patterns in Rust](https://www.youtube.com/watch?v=Pm_oO0N5B9k) (PDRust, 2016)
- Pascal Hertleif의 [Writing Idiomatic Libraries in Rust](https://www.youtube.com/watch?v=0zOg8_B71gE) (RustFest, 2017)
- Nicholas Cameron의 [Rust Programming Techniques](https://www.youtube.com/watch?v=vqavdUGKeb4) (LinuxConfAu, 2018)

## 온라인 책

- [The Rust API Guidelines](https://rust-lang.github.io/api-guidelines) — Rust 라이브러리 API의 일관성과 사용성을 위한 지침입니다.

이 자료는 출발점입니다. 패턴을 적용하기 전에는 해당 패턴이 해결하려는 문제와 현재 프로젝트의 요구를 비교하세요.
