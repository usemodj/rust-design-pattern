# 관용구

[관용구](https://en.wikipedia.org/wiki/Programming_idiom)는 공동체에서 널리 쓰이고 합의된 코드 스타일, 지침, 표현 방식입니다. 관용적인 코드는 다른 개발자가 의도를 빠르게 파악하도록 돕습니다.

컴퓨터는 컴파일러가 생성한 기계어를 실행하지만, 소스 코드는 주로 사람이 읽고 고칩니다. 그러므로 동작이 같다면 단순하고 익숙한 표현을 선택하는 것이 좋습니다. 이는 불필요한 복잡성을 피하라는 **KISS 원칙**(Keep It Simple, Stupid)과도 맞닿아 있습니다.

Rust의 관용구는 소유권, 빌림, 타입 추론, 반복자와 같은 언어 기능을 자연스럽게 활용합니다. 예를 들어 함수가 값을 소유할 필요가 없다면 소유 타입을 받기보다 빌린 타입을 인자로 받는 편이 호출자에게 더 유연할 수 있습니다.
