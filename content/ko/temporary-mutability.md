# 임시 가변성

## 설명

데이터를 준비하고 가공하는 동안에는 변경이 필요하지만, 그 이후에는 값을 읽기만 하고 더는 수정하지 않는 경우가 많습니다. 이때 가변 변수의 값을 불변 변수로 다시 정의하면, 변경이 필요한 시점과 이후 읽기 전용으로 사용하는 시점을 코드에 분명히 나타낼 수 있습니다.

이 방식은 중첩 블록 안에서 데이터를 가공하거나, 가변 변수를 불변 변수로 재바인딩해 사용할 수 있습니다.

## 예제

벡터를 사용하기 전에 정렬해야 한다고 가정해 봅시다.

### 중첩 블록 사용하기

블록 안에서 벡터를 가변으로 만들고 정렬한 뒤, 블록의 마지막 표현식으로 반환합니다. 블록 밖에서는 `data`가 불변 바인딩입니다.

```rust,ignore
let data = {
    let mut data = get_vec();
    data.sort();
    data
};

// Here `data` is immutable.
```

### 변수 재바인딩하기

같은 이름으로 불변 변수를 다시 바인딩할 수도 있습니다. 이후의 코드에서는 두 번째 `data`를 사용하므로 벡터를 변경할 수 없습니다.

```rust,ignore
let mut data = get_vec();
data.sort();
let data = data;

// Here `data` is immutable.
```

## 장점

컴파일러가 가공이 끝난 뒤 데이터를 실수로 변경하지 않도록 보장합니다. 가변성을 필요한 구간으로 제한하고, 그 이후에는 불변으로 사용한다는 의도를 타입 검사로 표현할 수 있습니다.

## 단점

중첩 블록을 사용하면 블록 본문에 들여쓰기가 추가됩니다. 또한 블록에서 값을 반환하기 위한 줄이 하나 더 필요합니다. 변수 재바인딩을 사용하는 경우에도 불변 바인딩을 만들기 위한 줄을 추가해야 합니다.
