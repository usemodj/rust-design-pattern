# 클로저에 변수 전달하기

## 설명

클로저는 기본적으로 주변 환경의 변수를 빌려 캡처합니다. `move` 클로저를 사용하면 캡처하는 값을 클로저로 이동할 수 있습니다. 하지만 모든 변수를 똑같이 처리하고 싶지는 않을 때가 많습니다. 일부 변수는 이동하고, 일부 데이터는 복제해 전달하거나, 일부는 참조로 빌리거나, 클로저에 전달하기 전에 다른 방식으로 변환할 수 있습니다.

이처럼 변수마다 캡처 방식을 다르게 지정하려면 별도 스코프 안에서 변수 이름을 다시 바인딩하는 방법을 사용할 수 있습니다.

## 예제

다음 예제에서는 `num1`을 클로저로 이동하고, `num2`는 복제하며, `num3`는 참조로 빌립니다. 별도 블록 안에서 다시 바인딩한 이름을 `move` 클로저가 캡처하므로 각 변수의 처리 방식이 클로저 정의 가까이에 모여 있습니다.

```rust
use std::rc::Rc;

let num1 = Rc::new(1);
let num2 = Rc::new(2);
let num3 = Rc::new(3);
let closure = {
    // `num1` is moved
    let num2 = num2.clone();  // `num2` is cloned
    let num3 = num3.as_ref();  // `num3` is borrowed
    move || {
        *num1 + *num2 + *num3
    }
};

println!("closure: {}", closure());
```

아래처럼 클로저를 정의하기 전에 복제와 대여를 바깥에서 처리할 수도 있습니다. 하지만 이 경우 클로저가 사용하는 변수 이름이 원래 이름과 달라지고, 복제·대여한 값이 클로저 정의와 떨어져 있어 각 값이 왜 필요한지 파악하기 어렵습니다.

```rust
use std::rc::Rc;

let num1 = Rc::new(1);
let num2 = Rc::new(2);
let num3 = Rc::new(3);

let num2_cloned = num2.clone();
let num3_borrowed = num3.as_ref();
let closure = move || {
    *num1 + *num2_cloned + *num3_borrowed;
};
```

## 장점

- 복제한 값과 빌린 값의 준비 과정을 클로저 정의와 한곳에 모을 수 있어 각각의 목적이 더 명확해집니다. 별도 스코프에 둔 값은 클로저가 실제로 사용하지 않더라도 그 스코프의 수명에 따라 정리됩니다.
- 데이터를 복제했는지 이동했는지와 관계없이 클로저 안에서 바깥 코드와 같은 변수 이름을 사용할 수 있습니다.

## 단점

별도 스코프가 추가되어 클로저 본문에 들여쓰기가 더해집니다.
